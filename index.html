Raffle Lioness Search Tool

This tool is NOT FINALIZED! It is a personal project I have been working on for a while and it's usable enough, however it is not really "user friendly" yet. A help prompt and known bugs prompt will be added soon!

The raffle lioness database this program pulls from is the official Lioden Wiki's raffle lioness directories. I have a program that is scheduled to run every week that reads the most recent raffle lioness directory webpage, parses the HTML, then writes to a JSON that gets pushed to this project's Github. As such, given nothing happens to the directories or large HTML changes happen to them, this tool should continue to update even if I stop playing. If something breaks them, the JSON directory should be archived in old Github pushes and you're free to use it for your own RL tools.
